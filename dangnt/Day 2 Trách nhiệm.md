1. **Cầu nối (The Link)**: DevOps là cầu nối giữa **Development** (đội ngũ viết code, tạo tính năng) và **Operations** (đội ngũ quản lý server, hạ tầng).
2. **Hiểu cả hai thế giới**:
    - Bạn không cần phải code giỏi như Developer, nhưng bạn cần hiểu cách ứng dụng hoạt động, cách nó kết nối với database, các service khác.
    - Bạn không cần phải là chuyên gia mạng (Network Expert), nhưng bạn cần biết cơ bản về IP, DNS, Port để cấu hình cho các service nói chuyện với nhau.
3. **Mục tiêu chính**: Làm sao để đưa code từ máy của Developer lên môi trường Production (đến tay người dùng) một cách **nhanh chóng, tự động và an toàn**.
4. **Jack of all trades**: Bạn sẽ cần biết nhiều thứ một chút (Linux, Cloud, Container, Coding cơ bản...) thay vì chỉ chuyên sâu một thứ.

**Câu hỏi ôn tập:** Theo bạn, một DevOps Engineer có nhất thiết phải biết viết code (programming) thành thạo như một Software Developer không? Tại sao?
Answer: Không nhất thiết phải viết code giỏi như một Software Developer, cũng không cần phải là chuyên gia mạng (Network Expert) mọi thứ cần là hiểu biết đủ, cơ bản để hiểu và cấu hình.
