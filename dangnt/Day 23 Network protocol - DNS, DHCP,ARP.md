**1.Arp (Address resolution protocol)
- Giúp tìm địa chỉ MAC thông qua IP
- Ví dụ: Máy A muống gửi tin cho IP 192.168.1.5, nó sẽ hét lên : "Ai có IP này thì cho xin cái MAC Addresss coi!".
**2. DNS (Domain Name System)**
- Danh bạ điện thoại của internet
- Giúp chuyển tên miền dễ nhớ (google.com) thành IP khó nhớ (142.250.1.1)
- Câu nói nổi tiếng : *"It's always DNS"* (Lõi mạng phần lớn là do DNS)
**3. DHCP(Dynamic Host Configuration Protocol)**
- Người phát số thứ tự
- Tự động cấp phát IP, subnet mask, gateway để có thể truy cập internet mà không cần system admin cấp tay.
**4. HTTP/HTTPS**
